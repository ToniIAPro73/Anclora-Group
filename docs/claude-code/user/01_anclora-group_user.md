# Anclora Group — Guía de Usuario

**Audiencia:** Equipo interno Anclora | **Fecha:** Abril 2026

---

## ¿Qué es Anclora Group?

Anclora Group es el **portal corporativo central** de la empresa. Es tu punto de entrada único para acceder a todas las herramientas y aplicaciones del ecosistema Anclora según tu rol.

Piensa en él como el hub de operaciones de Anclora: desde aquí puedes navegar a cualquier aplicación del grupo sin necesidad de recordar múltiples direcciones web.

---

## ¿Para quién es?

- **Equipo directivo y administradores** del grupo Anclora
- **Empleados internos** que necesitan acceder a las herramientas del ecosistema
- **Responsables de operaciones** del grupo

No es una aplicación de cara al cliente externo.

---

## Cómo acceder

1. Accede a la URL del portal Anclora Group (facilita el administrador)
2. Introduce tu usuario y contraseña corporativos
3. El sistema te mostrará las aplicaciones disponibles según tu rol

---

## Qué puedes hacer

### Navegación del portal

El portal se organiza en cuatro secciones:

- **Workspace** (`/workspace`): tu home operativa tras iniciar sesión
- **Aplicaciones** (`/apps`): catálogo con todas las apps que tu rol tiene autorizadas
- **Arquitectura** (`/architecture`): mapa de las capas del ecosistema
- **Documentación** (`/docs`): documentación interna, incluido el documento de arquitectura (PDF)

### Gestión de Sesiones

- Tu sesión se mantiene activa con una cookie segura
- Para cerrar sesión, usa la opción correspondiente en el portal

## Preguntas Frecuentes

**¿Olvidé mi contraseña, qué hago?**  
Contacta al administrador del sistema para que restablezca tus credenciales.

**¿No veo una aplicación que necesito?**  
Tu acceso depende de tu rol asignado. Contacta al administrador para solicitar acceso adicional.

**¿Puedo cambiar el idioma o el tema visual?**  
No. El portal está disponible únicamente en español y no existe selector de idioma (la traducción real es una fase futura). El tema visual es oscuro por defecto para todo el portal; no hay interruptor de tema visible para el usuario.
