# Anclora Content Generator AI — Guía de Usuario

**Audiencia:** Equipo editorial, marketing y comunicación de Anclora | **Fecha:** Abril 2026

---

## ¿Qué es Anclora Content Generator AI?

Anclora Content Generator AI es el **motor editorial inteligente** de Anclora Private Estates. Es una plataforma de inteligencia de contenido especializada en Real Estate de lujo que ayuda al equipo de marketing y comunicación a crear, gestionar y publicar contenido de alta calidad de forma mucho más eficiente.

No es un generador genérico de texto. Está entrenado y configurado con el conocimiento específico del mercado inmobiliario de lujo de Anclora.

---

## ¿Para quién es?

- **Equipo de marketing y comunicación** de Anclora
- **Redactores y content managers** que producen contenido sobre propiedades
- **Responsables de redes sociales** del grupo
- **Directores de marketing** que supervisan la estrategia de contenidos

## Cómo Funciona

### 1. Base de Conocimiento (Knowledge Base)

El sistema usa una base de conocimiento especializada en Real Estate de lujo. Puedes ingestar nuevos documentos y fuentes para enriquecer el conocimiento del sistema:

- Informes de mercado
- Regulaciones inmobiliarias
- Información de estilo de vida premium
- Datos de infraestructura y urbanismo
- Información editorial interna

### 2. Generación de Contenido

1. Selecciona el tipo de contenido que quieres crear
2. Indica el tema, la propiedad o la oportunidad de inversión
3. Escribe tu prompt o instrucciones (en español o inglés)
4. El sistema busca en la knowledge base el contexto relevante
5. Genera el contenido usando IA especializada
6. Revisa, edita y aprueba desde el dashboard

### 3. Flujo Editorial

```
Borrador (Draft) → Revisión → Aprobado → Programado → Publicado
```

---

## Reglas de Uso

- Siempre revisa el contenido generado antes de publicar
- El sistema ayuda al equipo, pero no reemplaza el juicio editorial humano
- Asegúrate de que el contenido publicado refleja los valores y el tono de Anclora Private Estates
- No compartas acceso a la plataforma con personas externas al equipo
